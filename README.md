# REDES-M5-DESENVOLVIMENTO DE PAGINAS WEB DINAMICAS

# Exercícios de JavaScript

Este repositório contém dois exercícios práticos desenvolvidos em **HTML, JavaScript e Bootstrap**, com o objetivo de praticar a manipulação do DOM e a interação com elementos de uma página web.

## 📁 Estrutura do projeto

```text
.
├── exerc-01/
│   ├── js/
│   │   └── app.js
│   └── orador.html
│
└── exerc-02/
│   ├── js/
│   │   └── app.js
│   └── contador.html
```

## 💻 Exercício 01 — Informação do Orador

O primeiro exercício apresenta uma página com informações sobre um evento tecnológico e um orador.

Ao clicar no botão **«Atualizar informação»**, o JavaScript atualiza os conteúdos da página através da manipulação do DOM.

**Informações apresentadas:**
- Nome do evento: Web Summit 2026;
- Localização: Lisboa, Portugal;
- Mensagem de boas-vindas;
- Nome e descrição do orador: António Guterres.

**Ficheiros principais:**
- `orador.html` — estrutura da página;
- `js/app.js` — dados do evento e funcionamento do botão.

## 🔢 Exercício 02 — Contador de Participantes

O segundo exercício consiste num contador que permite adicionar e remover participantes.

**Funcionalidades:**
- Adicionar participantes;
- Remover participantes;
- Impedir que o contador ultrapasse os 10 participantes;
- Impedir que o contador fique abaixo de 0;
- Apresentar mensagens quando se atinge o limite máximo ou quando já não existem participantes para remover.

**Ficheiros principais:**
- `contador.html` — estrutura da página do contador;
- `app.js` — lógica de funcionamento do contador.

## 🛠️ Tecnologias utilizadas

- **HTML5** — estrutura das páginas;
- **JavaScript** — lógica e interatividade;
- **Bootstrap 6 Alpha** — estilos e componentes visuais.

## ▶️ Como executar

1. Descarrega ou clona este repositório.
2. Abre a pasta do exercício que pretendes consultar.
3. Abre o respetivo ficheiro HTML num navegador:
   - Exercício 01: `exerc-01/orador.html`
   - Exercício 02: `exerc-02/contador.html`

Não é necessária qualquer instalação adicional. É necessária uma ligação à Internet para carregar o Bootstrap através do CDN.

## 🎯 Objetivo

Praticar os conceitos básicos de JavaScript, nomeadamente variáveis, funções, eventos, condições e manipulação de elementos HTML através do DOM.
